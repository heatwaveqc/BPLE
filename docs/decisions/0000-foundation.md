# 0000 — Project identity and constitutional axioms

- Status: Accepted
- Date: 2026-11-17
- Approval: project owner's inception discussion explicitly selected BPLE as project/searchable name and The Grammar as official programming language name, and requested publishing the five axioms.

The [constitution](../../spec/AXIOMS.md) records the original five principles and subsequent approved amendments; [decision 0009](0009-extensibility-axiom.md) adds Axiom VI. BPLE expands to Best Programming Language Ever. The project tagline is the working phrase "One grammar. Any language." Component names, concrete grammar, host/backend, file extension and license are not part of this decision.

The repository will separate specification, lexicons, implementation, testing and design records. This organizational scaffolding is provisional and does not itself standardize language behavior.
