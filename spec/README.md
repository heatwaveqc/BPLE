# The Grammar Standard

The [constitution](AXIOMS.md) is the governing foundation. This directory will own the versioned normative language specification independently of any compiler implementation.

Planned sections: lexical token inventory and profile contract; formal grammar (notation TBD); identifiers, Unicode, literals and escaping; declarations, scoping and types; evaluation and effects; modules and interoperability; diagnostics and execution conformance; spoken/written representation.

Accepted design requirements: [Enclosures and diagnostic identities](ENCLOSURES.md). Exact grammar productions and allocation details remain open.

No concrete grammar productions or token inventory are standardized yet. Future normative changes require an accepted decision from [the register](../docs/decisions/README.md), specified semantics and conformance examples. Examples and implementation do not override this standard. Distinguish normative requirements from illustrative text and unspecified behavior. Version the standard and profile compatibility together explicitly.
